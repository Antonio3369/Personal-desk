# Personal Desk 视觉升级方案

> 日期：2026-07-31  
> 设计稿：[Ardot 画布](https://ardot.tencent.com/file/709867558720813)

---

## 一、项目诊断：5 个视觉问题

| # | 问题 | 现状 | 影响 |
|---|------|------|------|
| 1 | **全灰配色无重点** | 全站 Stone 灰阶，无强调色 | 页面"平"，用户找不到视觉锚点 |
| 2 | **StatCard 无智能感** | 纯数字+标题，无趋势/状态/对比 | 看起来像静态报表，不像智能工作台 |
| 3 | **衬线字体不适合工具场景** | 全站 Noto Serif SC | 正文阅读效率低，工具感弱 |
| 4 | **卡片扁平无深度** | 无阴影、无层次区分 | 信息区块之间缺乏视觉分隔 |
| 5 | **无智能视觉线索** | 缺少 AI 摘要、状态提示、人脉温度等 | "智能"只停留在功能层面，视觉上感知不到 |

## 二、设计决策

### 2.1 配色方案：莫兰迪灰蓝 + 香槟金

| 角色 | 色值 | 用途 |
|------|------|------|
| 页面底色 | `#EEF0F3` | 主背景，柔和不刺眼 |
| 侧栏底色 | `#E4E9EF` | 与主区域形成微妙的层次区分 |
| 主色（活跃蓝） | `#5B7A99` | 选中态、进行中状态、导航高亮 |
| 香槟金 | `#C9A96A` | 关键数字、CTA 按钮、AI 摘要卡片边框 |
| 琥珀 | `#C9956A` | "等待对方"状态、"已等 X 天"提示 |
| 鼠尾草绿 | `#7BA89A` | "已完成"状态、积极趋势 |
| 文字主色 | `#2D3748` | 正文 |
| 文字次色 | `#718096` | 辅助说明 |

**为什么选这个方向：**
- 莫兰迪灰蓝底色稳重但不沉闷，适合长时间工作场景
- 香槟金作为"点睛色"用量克制（数字、CTA、AI 元素），制造高级感
- 语义色系统让状态一目了然，不需要额外文字解释

### 2.2 字体策略：衬线留品牌位 + 正文切无衬线

| 层级 | 字体 | 场景 |
|------|------|------|
| 品牌 / 大标题 | **Noto Serif SC**（衬线） | Logo、页面主标题、欢迎语 |
| 正文 / UI | **Inter**（无衬线） | 卡片内容、列表、表单、按钮、数据 |

**为什么这么分：**
- 衬线体保留"个人工作台"的品牌温度感，不沦为纯工具
- 正文切无衬线提升信息密度场景下的阅读效率
- 两者搭配是"有调性的工具"的经典组合

### 2.3 智能化方向（全选）

| 模块 | 升级内容 |
|------|----------|
| **Dashboard 升级** | StatCard 加入语义色 + 趋势箭头 + "已等 X 天"提示 |
| **待办看板** | 四列看板（未开始/进行中/等待对方/已完成），状态色圆点 + 城市标签 |
| **人脉温度** | 联系人卡片显示"上次联系 X 天前"，超期变琥珀色提醒 |
| **视觉升级** | 全站换肤莫兰迪灰蓝+香槟金，卡片加阴影层次 |

## 三、设计 Token 系统

### 3.1 颜色 Token

```css
:root {
  /* 背景层 */
  --color-bg-page: #EEF0F3;
  --color-bg-sidebar: #E4E9EF;
  --color-bg-card: #FFFFFF;

  /* 品牌色 */
  --color-primary: #5B7A99;
  --color-primary-hover: #4A6A89;

  /* 点缀色 */
  --color-gold: #C9A96A;
  --color-amber: #C9956A;
  --color-sage: #7BA89A;

  /* 文字 */
  --color-text-primary: #2D3748;
  --color-text-secondary: #718096;
  --color-text-on-primary: #FFFFFF;

  /* 语义状态 */
  --color-status-pending: #A0AEC0;   /* 未开始 - 灰 */
  --color-status-active: #5B7A99;    /* 进行中 - 蓝 */
  --color-status-waiting: #C9956A;   /* 等待对方 - 琥珀 */
  --color-status-done: #7BA89A;      /* 已完成 - 绿 */
}
```

### 3.2 阴影 Token

```css
--shadow-card: 0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06);
--shadow-card-hover: 0 4px 12px rgba(91,122,153,0.12), 0 2px 4px rgba(0,0,0,0.06);
--shadow-gold-glow: 0 0 0 1px rgba(201,169,106,0.3);
```

### 3.3 字体 Token

```css
--font-serif: 'Noto Serif SC', serif;     /* 品牌位 */
--font-sans: 'Inter', system-ui, sans-serif; /* 正文/UI */
```

## 五、代码实施计划

按以下顺序改造代码，每步可独立验证：

| 步骤 | 文件 | 改动内容 |
|------|------|----------|
| 1 | `src/app/globals.css` | 加入 CSS 变量（颜色/阴影/字体），更新 Tailwind 主题映射 |
| 2 | `src/app/layout.tsx` | 引入 Inter 字体，设置 `--font-sans` 为默认 |
| 3 | `src/components/ui-shell.tsx` | 侧栏底色改 `#E4E9EF`，导航选中态改蓝 `#5B7A99`，卡片加阴影 |
| 4 | `src/app/(app)/page.tsx` | StatCard 数字改语义色，待办列表加状态圆点，联系人加"已等 X 天" |
| 5 | 业务页适配 | 待办/笔记/联系人页按设计稿同步调整配色和状态色 |
